# Engenharia de Prompt - Fundamentos

Repositório criado para a atividade de fixação da Unidade I - Fundamentos de IA e Engenharia de Prompt.

## Objetivo

Comparar o resultado de um prompt genérico com o resultado de um prompt estruturado usando a fórmula:

> **Papel + Objetivo + Contexto + Formato**

O tema escolhido foi **Machine Learning**.

## 1. Prompt genérico

### Pedido

> O que é Machine Learning?

### Resposta

Machine Learning, ou aprendizado de máquina, é uma área da Inteligência Artificial em que sistemas aprendem padrões a partir de dados para fazer previsões, classificações ou tomar decisões. Em vez de receber todas as regras programadas manualmente, o sistema analisa exemplos e ajusta um modelo para lidar com novos casos.

## 2. Prompt estruturado

### Estrutura utilizada

- **Papel:** professor paciente de introdução à computação.
- **Objetivo:** explicar o conceito de Machine Learning.
- **Contexto:** público iniciante, sem conhecimento prévio de Inteligência Artificial.
- **Formato:** dois parágrafos, linguagem simples e uma analogia com esportes.

### Pedido

> Atue como um professor paciente de introdução à computação. Explique o conceito de Machine Learning para uma pessoa iniciante, sem conhecimento prévio de Inteligência Artificial. Use linguagem simples, faça uma analogia com esportes e responda em dois parágrafos.

### Resposta

Machine Learning, ou aprendizado de máquina, é uma forma de fazer um computador aprender com exemplos. Em vez de programar uma regra para cada situação, fornecemos dados para que o sistema encontre padrões e use esses padrões ao analisar novos casos. Por exemplo, ele pode aprender a identificar mensagens indesejadas observando muitos exemplos de mensagens classificadas como spam ou como mensagens normais.

É parecido com o treinamento de um atleta ou de uma equipe esportiva. O time observa muitos lances, pratica, recebe avaliações e melhora suas decisões com base nos exemplos anteriores. O resultado não é uma compreensão humana do jogo: é um modelo matemático que calcula quais padrões parecem mais prováveis. Por isso, a qualidade e a variedade dos dados de treinamento influenciam diretamente a qualidade das previsões.

## 3. Análise crítica

A resposta do prompt estruturado foi mais útil para o público definido. O prompt genérico informa o conceito, mas deixa em aberto o nível de profundidade, o tom e o formato da explicação. Já o prompt estruturado reduziu a ambiguidade ao indicar quem deveria responder, para quem, com qual objetivo, usando qual exemplo e em quantos parágrafos.

A estrutura também tornou o resultado mais fácil de avaliar: a resposta precisava ser acessível, conter uma analogia esportiva e respeitar dois parágrafos. Isso não garante que a informação esteja correta, portanto a resposta ainda precisa ser lida criticamente e, quando necessário, comparada com fontes confiáveis.

## 4. Conclusão

Um prompt mais claro tende a produzir uma resposta mais direcionada e consistente. A engenharia de prompt não substitui o conhecimento do usuário: ela ajuda a comunicar melhor a tarefa e a avaliar se o resultado atende ao objetivo original.
