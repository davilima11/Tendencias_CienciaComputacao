Como funciona

Escolha a linguagem acima do campo, cole um código em Python ou JavaScript e eu explico cada linha. Depois dá para pedir "explica a linha 4", "resume" ou perguntar "o que é um for?".

Eu não escrevo nem corrijo código. Meu papel é te ajudar a entender.

Experimente

Tudo roda no seu navegador: o código que você cola não é enviado para servidor nenhum. Senhas e chaves são escondidas antes da análise, e a conversa some quando você fecha a página.
