# Códigos de exemplo

Códigos prontos para testar o DecifraBot. Abra um arquivo, copie o código, escolha a linguagem no seletor (Python ou JavaScript) e cole no chat do [site](https://davilima11.github.io/Tendencias_CienciaComputacao/unidade4-ProjetoA1/).

| Arquivo | Linguagem | O que dá para ver |
|---|---|---|
| [01_lista_de_compras.py](01_lista_de_compras.py) | Python | `input`, lista, `while` e `for` |
| [02_situacao_do_aluno.py](02_situacao_do_aluno.py) | Python | Função com `if`, `elif` e `else` |
| [03_adivinhe_o_numero.py](03_adivinhe_o_numero.py) | Python | Jogo com `random` e `while` |
| [04_codigo_que_veio_da_ia.py](04_codigo_que_veio_da_ia.py) | Python | Alertas: apaga arquivos e pasta, manda dados pela internet e tem uma chave escrita no código (o bot esconde) |
| [05_busca_no_banco.py](05_busca_no_banco.py) | Python | Alerta de SQL Injection |
| [06_tabuada.js](06_tabuada.js) | JavaScript | `for` com contador e template string |
| [07_carrinho_de_compras.js](07_carrinho_de_compras.js) | JavaScript | Array de objetos, `filter`, `map` e `for...of` |
| [08_botao_da_pagina.js](08_botao_da_pagina.js) | JavaScript | Clique de botão e alerta de XSS com `innerHTML` |
| [09_codigo_avancado.py](09_codigo_avancado.py) | Python | `class` e `lambda`, que o bot avisa que ainda não sabe explicar |

Depois da explicação, dá para continuar a conversa: "explica a linha 3", "resume" ou "o que é um while?".

Se colar um código JavaScript com Python escolhido (ou o contrário), o bot avisa e explica depois que você trocar no seletor.

A chave no arquivo 04 é inventada, só para mostrar o aviso.
